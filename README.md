Моя первая игра — Рулетка 🎰
Это моя первая игра на Python! Я сделал её, чтобы научиться программировать.
Что умеет игра:
- Ставить на чётное или нечётное число.
- Случайно выпадает число от 0 до 36.
- Если угадал — выигрываешь деньги, если нет — теряешь.
- Баланс сохраняется в файл balance.txt, так что он не сбрасывается после перезапуска.
Как играть:
1. Скачай файлы ytop.py и balance.txt.
2. Положи их в одну папку.
3. Запусти в терминале: python ytop.py
4. Следуй инструкциям на экране!
